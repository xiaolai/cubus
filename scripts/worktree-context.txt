# The ignored agent context every git worktree of this repo SHARES with the main checkout.
#
# One path per line, relative to the repo root; `#` starts a comment. Each path is gitignored, so
# git gives a worktree none of them, and a copy made by hand drifts silently. Every one is LINKED
# from the main checkout by scripts/link-worktree-context.sh, never copied.
#
# Read by three things, so this file is the one list:
#   - scripts/link-worktree-context.sh   creates the links (and refuses to replace a differing copy)
#   - apps/web/test/worktree-context.test.mjs   asserts every other worktree links each path, and
#     that every AGENTS.md / CLAUDE.md git ignores in this checkout is named here
#   - scripts/check-on-clone.sh   hides each path, since a clone has none of them
#
# A new area rule file is added here, as its AGENTS.md and the CLAUDE.md importing it.
