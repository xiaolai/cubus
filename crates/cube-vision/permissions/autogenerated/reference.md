## Default Permission

Allows cube-vision to list cameras, load the model, capture frames and run inference.

#### This default permission set includes the following:

- `allow-probe`
- `allow-list-cameras`
- `allow-current-camera`
- `allow-load-model`
- `allow-open-camera`
- `allow-close-camera`
- `allow-next-detection`
- `allow-infer-frame`
